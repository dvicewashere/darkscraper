
# Go DarkWeb Scraper

Bu proje, **Go (Golang)** dili kullanılarak Tor'daki web sitesinin HTML içeriğini, ekran görüntüsünüçekip yerel dosyalara kaydeden bir **Dark Web Scraper** uygulamasıdır.

---

## Özellikler

- 🎯 **Hedef URL’yi yerel dosyadan alır**
- 🌐 **HTTP bağlantı durumunu kontrol eder**
- 💾 **Sayfanın HTML içeriğini kaydeder**
- 📸 **Sayfanın ekran görüntüsünü alır**

---

## Gereksinimler

- Go (Golang)
- Google Chrome
- Go kütüphanesi: chromedp, proxy, yaml.v3


Program çalıştığında,

results klasörü içerisine `png ve html` dosyaları kaydedilir.

`scan_report.log` → Yapılan işlemler Loglanır.

`sites.yaml` → Yerel dosyadaki websiteleri burada bulunur.
